
# DurationSetsAnimation 🎬

A simple iOS application demonstrating duration-based animations using Swift.

## 📱 About The Project

DurationSetsAnimation is an iOS development project focused on exploring animation duration and creating smooth, visually appealing UI animations.

## ✨ Features

- Duration-based animations
- Smooth animation transitions
- Interactive UI experience
- Clean and simple implementation
- Swift-based iOS development

## 🚀 Getting Started

1. Clone this repository.
2. Open `DurationSetsAnimation.xcodeproj` in Xcode.
3. Select an iOS Simulator or connected device.
4. Build and Run the project.
